## G1. 휴식 타이머 사운드 — 카운트다운 + 구분되는 종료음 (#2)

**현황**: 종료 시 단일 비프 1회. 진동은 iOS PWA `navigator.vibrate` 미지원 (플랫폼 제약 —
해결 불가, 사운드로 보완하는 것이 이 항목).

**변경** (`beep.ts` + `useRestTimer`):
1. 남은 3·2·1초에 **짧고 낮은 틱** (각 1회, ~80ms, 낮은 주파수)
2. 종료 시 **기존과 다른 2음 차임** (상행 2음, ~400ms) — "완전 종료"가 소리만으로 구분되게
3. 화면 켜져 있을 때만 (JS 정지 제약 동일). 복귀 시 놓친 종료는 차임 1회만 (틱 소급 금지)
4. 모든 소리는 G8의 ambient 세션 위에서 재생 (스포티파이 안 끊는 것이 전제)

**수용**: 3-2-1-종료가 서로 다른 소리로 들린다. 이미 지난 endTime 복원 시 틱이 몰아서
울리지 않는다 (타임스탬프 방식이므로 tick 스케줄도 endTime 파생으로 — 카운터 누적 금지).

## G2. 식단 "추가로 먹었어요" 필드 (#3)

**현황**: 대체(substitution)만 있음. 추가 섭취를 대체로 적으면 의미가 오염된다 —
전부 체크 + 대체 텍스트는 "일부 대체"로 해석돼 점수가 부당하게 깎이고,
LLM 분석에서 결식·대체·과식이 구분 불가.

**변경**:
1. `SlotRecord.addition?: { text: string; quality: 'similar' | 'other' | 'cheat' }` —
   substitution과 별개 (동시 존재 가능: 일부 대체 + 추가). 필드 추가는 하위호환이므로
   백업 SCHEMA_VERSION **유지** (파괴적 변경만 상향 원칙)
2. 슬롯 메뉴에 "추가로 먹었어요" → 텍스트 + 품질 3버튼 (기준 문구: 대체와 동일)
3. **점수**: 슬롯 완료 점수는 체크·대체 기준으로 먼저 구하고, addition이 있으면
   `min(기존, similar→1 / other→0.75 / cheat→0.5)` — 다 먹고 건강하게 추가한 건 무벌점,
   치팅 추가는 완수했어도 반영. 근거: 감량기에 "계획 완수 + 야식"은 완수가 아니다
4. 내보내기: `+ 추가: "라면 반 개" — 치팅` 줄. 단백질 추정에는 addition 미반영 (미지수)

**수용**: dietOps·diet 점수·dietExport 테스트에 addition 케이스. 기존 기록(필드 없음) 무영향.

## G3. 훈련일/휴식일 토글 명확화 (#4)

**현황**: 상태·기능이 화면에서 안 읽힌다 (실사용 첫 피드백).

**변경**:
1. 토글 → **세그먼트 컨트롤**: `[훈련일 · 6끼] [휴식일 · 5끼]` — 선택된 쪽 배경 강조
   (aria-pressed + 시각 상태. 기존 Phase 세그먼트 스타일 재사용)
2. 아래 캡션 한 줄: 훈련일 = "훈련 전·직후 쉐이크가 별도 끼니입니다" /
   휴식일 = "쉐이크·바나나를 오후 간식 한 번으로 합칩니다 (총량 동일)"
3. 완료 세션이 생겨 자동 고정된 날은 세그먼트 비활성 + 자물쇠 아이콘 + "오늘 운동 기록이
   있어 훈련일로 고정됨"

**수용**: 처음 보는 사람이 캡션만 읽고 기능을 이해할 수 있다 (문구가 스펙이다).

## G4. 식단 일 기록 삭제 (#5)

**현황**: 세션은 삭제 가능, 식단은 불가 — 절반은 의도(날짜 키 덮어쓰기 편집으로 충분하다고
봤음)였으나 테스트 기록 정리가 불가능한 것이 확인됨.

**변경**: 오늘 화면 하단 + 과거 편집(DietDayEditor)에 "이 날 식단 기록 지우기" —
세션 삭제와 같은 2단 확인 패턴, 기록된 슬롯 수 표시. DietDay 행 삭제 (플랜 선택도 초기화).

**수용**: 삭제 후 캘린더 링이 사라지고, 다음 백업에 반영된다. dietOps 테스트.

## G5. iOS 자동완성(연락처 제안) 억제 (#7)

**현황**: 입력 필드 포커스 시 키보드 위에 연락처 자동완성 제안 — iOS QuickType이
이름 없는 텍스트 필드를 연락처 필드로 오인하는 것.

**변경**: 앱의 모든 input/textarea에 일괄 적용 (공통 컴포넌트化 또는 전수 적용):
`autoComplete="off"` `autoCorrect="off"` `autoCapitalize="off"` `spellCheck={false}`,
`name` 속성 제거(또는 `data-` 성격의 중립 문자열), 숫자 입력은 기존 `inputMode` 유지.

**⚠ 정직한 한계**: iOS는 `autocomplete="off"`를 완전히 존중하지 않는 것으로 알려져 있다.
위 조합(특히 name 제거 + inputMode)이 통상 제안을 없애지만 **보장은 실기기 확인으로만
가능**하다. 적용 후에도 남으면 그 필드의 속성 조합을 기록하고 이 문서에 결과를 남길 것
(짐작 반복 금지).

## G6. 가독성 패스 — 색 토큰만 (#8)

**현황**: 보조 텍스트·플레이스홀더·칩("B그룹 · 휴식 90초")의 대비가 낮다.

**변경** (global.css 토큰만, 구조·레이아웃 변경 금지):
1. `--text-dim` 밝기 상향 — 보조 텍스트 대비 **4.5:1 이상** 목표 (현재 추정 ~3.5:1)
2. placeholder 색 별도 토큰으로 분리 + 상향
3. `.chip` 배경 한 단계 밝게 + 글자색 상향 (뱃지가 정보인데 장식 수준 대비였음)
4. 다크 테마 유지. 액센트·경고색 불변. 변경 전후 스크린샷 비교를 커밋에 첨부

**수용**: 사용자 육안 확인이 최종 기준. 과하게 밝아져 눈부시면 되돌린다 — 토큰 3개라 싸다.

## G7. 템포 가이드 모드 (#9) — 이 라운드 최대 작업

**무엇**: 세트 중 수축·이완 리듬을 소리+시각으로 안내 (명상앱 호흡 가이드 방식).

**템포 데이터** — 루틴 문서 3장이 이미 규정 (그룹 수준 상수, 종목별 시드 변경 불요):

| 그룹 | 수축(올림) | 정점 짜내기 | 이완(내림) | 신장 정지 | 근거 |
|---|---|---|---|---|---|
| A | 1초 | — | 2초 | — | 문서 3장 "내릴 때 2초, 통제" |
| B | 1초 | 1초 | 3초 | 1초 | 문서 3장 B그룹 실행 규칙 (3-1-1-1) |
| core | 2초 | 1초 | 2초 | — | "천천히 통제" |

**동작**:
1. 설정에 "템포 가이드" 토글 (기본 꺼짐). 켜면 세트 행에 가이드 버튼(♩) 노출
2. 탭 → **3-2-1 카운트인** (G1 틱과 같은 소리) → 페이즈 루프 시작.
   페이즈 순서: 수축 → (짜내기) → 이완 → (정지) → 반복. 머신 운동은 수축부터 시작
3. **소리**: 수축 = 상행 톤, 이완 = 하행 롱톤(길이 = 이완 초), 정지·짜내기 = 저음 틱.
   시각: 페이즈에 따라 커졌다 작아지는 링 + 페이즈 라벨 + **반복수 카운터**
4. **종료 탭 → 카운트된 반복수를 그 세트 reps에 자동 입력** (수정 가능) — 가이드가
   기록 마찰을 오히려 줄인다. 세트 체크는 별도 (기존 흐름 유지)
5. 가이드 중 Screen Wake Lock 시도 (`navigator.wakeLock`, iOS 16.4+) — 실패 무시.
   화면이 꺼지면 가이드도 멈춘다 (플랫폼 제약, 안내 문구 1회)
6. 마지막 2~3회에서 속도가 느려지는 건 정상이자 목표(문서 13장) — 가이드 리듬을
   못 따라가기 시작하면 그게 세트 종료 신호라는 안내를 토글 설정 설명에 한 줄

**수용**: 페이즈 타이밍이 타임스탬프 파생(카운터 누적 금지 — 타이머와 동일 원칙).
reps 자동 입력 단위 테스트. B그룹 한 사이클 = 6초(1+1+3+1) 검증.

## G8. 오디오 세션 — 스포티파이 정지 금지 (#10)

**현황**: 앱의 Web Audio가 iOS 기본 오디오 세션으로 잡혀 다른 앱 재생을 중단시키는
경우가 있음 (resumeAudio/unlockAudio 시점 추정).

**변경**:
1. `navigator.audioSession.type = 'ambient'` 설정 (지원 시) — **부팅 시 + resumeAudio 직전**
   양쪽. ambient는 다른 앱 오디오와 믹스되고 무음 스위치를 존중한다
2. `<audio>` 엘리먼트 미사용 확인 (Web Audio only 유지)
3. G1 틱·차임, G7 가이드 톤 전부 이 세션 위에서 재생
4. 폴백: `navigator.audioSession` 미지원 브라우저에서는 현행 유지 + 이 문서에 실측 결과 기록

**수용 (실기기)**: 스포티파이 재생 중 → 앱 열기 / 세트 체크 비프 / 타이머 종료 차임 /
템포 가이드 1세트 — **네 경우 모두 음악이 끊기지 않는다.** 이것이 이 라운드에서
가장 중요한 실기기 확인 항목이다.

**참고**: ambient는 무음 스위치를 존중하므로 "무음 스위치 ON이면 소리 없음"이 정상 동작이
된다 — 실기기에서 확인된 "진동 없음"과 함께, 무음 스위치 상태에서는 시각 신호만 남는다.
